# Security

Ghostline runs on your own PC and, if you publish it, behind a tunnel as a read-only site. The security model is
described in [docs/advanced.md](docs/advanced.md#security-model).

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/pr1tzy/ghostline/security/advisories/new) instead of a public
issue. Include what you found, how to reproduce it, and what an attacker could do with it.

Things that are in scope: anything that lets a public visitor change data, see other drivers' full names or local
file paths, run code, or get admin rights. Things that are out of scope: issues that need someone to already have
access to your PC.
